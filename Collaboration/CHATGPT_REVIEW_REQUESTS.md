# ChatGPT review requests

## R001 — repository upload gate

Review the documentation-only committed manifest in FIRST_COMMIT_REPORT.md before proposing the first push. Independently confirm the intended owner, private visibility, ignore behavior and absence of credentials/personal data. Source and held content are outside this commit; any future inclusion requires separate review. The first push requires explicit user approval. An empty private repository does not clear content for upload.

## R002 — visual reconstruction candidate

Review the actual approved final reference against the candidate, not against the old production layout. Confirm startup/hidden-state semantics, copied displayed-step numbering, border source-sampling fix, parchment hierarchy, two-window composition and remaining artwork limitations. Obtain client screenshots only after separate installation approval; redact unrelated personal/chat information before sharing remotely.

Acceptance must include fresh/default login, deliberate close, different characters, reload/relog, independent Zone visibility, all frame corners at supported sizes, original fallback and unchanged GPS. Automated tests alone are not visual acceptance.
