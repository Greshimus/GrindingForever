# Resource-location facts in the public build

The November 20, 2026 resource index contains 51,999 qualified typed location records across 47 maps: 25,295 mining, 26,034 herbalism and 670 fishing-pool members. These are source records, not a count of simultaneously active spawns or distinct guaranteed physical nodes.

The compact `resourceLocations` table in `GrindingForever/ForeverCatalog.lua` retains exact map percentages, node-type alternatives, known gameobject associations, source roles and evidence references. Co-located alternatives remain separate resource possibilities. Gathering node-type identifiers are not represented as gameobject identifiers.

Evidence includes QuestieDB Forever's pinned source data, separately attributed GatherMate2 data and recorded named-node approaches. Fishing references additionally retain the documented GatherRadar/AzerothCore conversion qualification. Source URLs and versions are retained per evidence group. Existing runtime notices retain the original upstream license and contributor qualifications; this document does not replace them with a uniform license claim.

Possible sites, inherited references, named-pool approaches and acquired-item approach locations have different roles. A player approach is not an exact node center. Hovering a pool does not establish that a later catch came from it. Unknown skill requirements and source relationships remain unknown.

Public observation data is normalized into resource facts. Repeated catches at the same item/map/position are consolidated. Private event times, event digests, import transport hashes and received quantities are excluded from that projection. The public table preserves the useful item, location, source and coordinate role; it does not distribute raw character activity or save files.

The owner maintains the source catalogue and import/capture tools privately. This public snapshot contains the gameplay data projection and ordinary named gathering-node memory, without the activity/performance collector or manual activity importer.

The Gathering first catalogue cross-references 270 naturally farmed recipe materials, including 89 reviewed additions, with positive recipe usage and qualified gathering or creature-source facts. It preserves all 51,999 typed sites. New material-source coordinates are existing source positions or documented area examples; they are not claims of measured spawn density or yield. Pinned source URLs, revisions and archive hashes are retained. Manufactured supplies, vendor-only supplies and the previously excluded raid-only materials remain outside the chooser.
